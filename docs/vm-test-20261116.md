## Findings incorporated into dotfiles

- **Python extraction:** the pinned, checksum-verified Python archive includes
  legitimate parent-relative terminfo aliases. Extraction now permits these only
  when normalization stays under `python/`, refers directly to a regular archive
  member and traverses no link ancestors. Archive traversal, escaping links,
  duplicate members and writes beneath link ancestors remain rejected. Parent
  links are not treated as tar hardlinks, whose target semantics differ.
- **Cold startup:** first package.el installation exceeded 300 seconds while
  making progress. Cold installation now has a separate 900-second budget;
  steady-state startup validation keeps 300 seconds. Timeout failures retain
  bounded stdout/stderr diagnostics and terminate the startup process group so
  package-installing children cannot continue in the background.
- **Failure reporting:** Ansible now parses the bootstrap's success JSON for
  `changed_when` only when its return code is zero. A failed command's original
  diagnostics remain visible instead of a secondary JSON filter error.

These corrections have local regression coverage. They do not establish a clean
VM replay of the corrected implementation.
